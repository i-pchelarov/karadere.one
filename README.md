# 🌊 Природосъобразно Карадере (karadere.one)

Официален уебсайт на сдружение **„Природосъобразно Карадере“** – платформа за обединяване на съмишленици, опазване на дюните и плажната ивица и насърчаване на къмпингуване с нулев отпечатък.

## 🎯 Цели на проекта
- Опазване на последните диви плажове и дюнни системи в България.
- Повишаване на културата за диво къмпингуване по принципите "Leave No Trace" (Без следа).
- Привличане на доброволци за акции по почистване и мониторинг.
- Набиране на средства за правни и теренни инициативи.

## 🛠️ Технологии
- HTML5 & CSS3
- Tailwind CSS (via CDN)
- Vanilla JavaScript (ES6)
- FontAwesome за икони

## 📁 Структура на проекта (v0.1)
- `index.html` - Главна начална страница
- `css/style.css` - Персонализирани стилове
- `js/main.js` - Логика за модали и мобилно меню
- `img/` - Изображения и икони

## 🚀 Пускане на сайта локално
Просто отворете `index.html` в предпочитания от вас уеб браузър.
